# Example 6 — Meander-Line LP-to-CP Polarization Converter: Scoring Recipe

**Serves:** [#104](https://github.com/parthalon025/Principle_RF_Engineer_Agent/issues/104)'s wayfinder map, "Not yet specified" item 1.

**Scope of this document.** This covers **Example 6 only** — the axial-ratio scoring recipe, its physical bound, and the RHCP/LHCP question. It does **not** resolve #129's stated gap for Examples 1/2 (the Mie-resonance magnetic-mirror and impedance-matched pair, which need an effective-medium-retrieval bound, not a polarization-conversion one — see `docs/example1-2-scoring-recipe.md`) — that is a structurally different physics question addressed separately, and nothing below should be read as having touched it.

**What this builds on, without re-deriving:** `docs/example6-polarization-converter-permittivity.md` already settled that εr is a free, rescalable design parameter (not load-bearing); `docs/seven-example-design-unknowns.md` §4 already established AR ≤ 3 dB as "the standard CP criterion" and that the patent sweeps 0–40° incidence; ADR-0047 already found "no bandwidth bound exists in the literature for polarisation conversion," citing Abdelrahman & Monticone. This document formalizes those into a scoring recipe and independently re-verifies the citations against primary sources rather than re-trusting them.

## 1. Primary objective

**Formula.** For a required band `[f_lo, f_hi]` and a set of tested incidence angles `Θ = {θ_1, …, θ_n}`:

```
AR_worst(θ) = max over f in [f_lo, f_hi] of AR(f, θ)        [dB], for each θ in Θ

Pass/fail:  candidate passes iff AR_worst(θ) ≤ AR_threshold, for every θ in Θ
Ranking:    Score = max over θ in Θ of AR_worst(θ)           (a second-level minimax, for sorting many candidates)
Objective:  margin(θ) = AR_threshold − AR_worst(θ), reported per angle — deeper margin scores better
```

`AR(f,θ)` itself is the standard polarization-ellipse formula from the co- and cross-polarized reflection coefficients (`R_co`, `R_cross`, with `δ` their phase difference): `AR = √[(a²+b²+√(a⁴+b⁴+2a²b²cos2δ)) / (a²+b²−√(...))]` where `a=|R_co|`, `b=|R_cross|`. This is standard antenna-theory textbook material (secondary-source-level confidence — not independently re-verified against a specific edition in this pass, the same caution the absorber-scoring doc applied to the `20n dB/decade` roll-off formula).

**In plain terms:** find the single worst frequency inside the required band, at each angle the design is tested at, and score the candidate on that worst point — not on its best point, and not on an average across the band.

**Why minimax, and an honest nuance the search surfaced.** Two things are true and worth keeping separate, because they answer different questions:

1. **The field's own reporting convention is already minimax-shaped.** "3 dB axial-ratio bandwidth" is *defined*, universally, as the band where AR stays at or below 3 dB — a threshold-everywhere-in-band quantity, exactly the same shape as the absorber family's "effective absorption bandwidth" (EAB, where RL < −10 dB everywhere in the reported range), which ADR-0041 already adopted with a worst-in-band objective. The 3 dB threshold itself is a much *stronger* de facto standard than the absorber field's own 70–99%/−6.99-to−20 dB spread — every source checked (antenna-theory references, ResearchGate community answers, patent specifications) states 3 dB with no real deviation except a stated tightening (2 dB for high-isolation dual-CP links) or loosening (4 dB, common for wide-scan-angle arrays). So minimax on this quantity is at least as well-grounded as it was for the absorber family, arguably more so.
2. **But the one paper found with an *explicit, quoted* internal optimizer fitness function does not use minimax — and it is a different kind of polarization converter, a distinction worth stating plainly rather than glossing over.** Borgese, Costa, Genovesi, Monorchio & Manara (Università di Pisa), *"Optimal Design of Miniaturized Reflecting Metasurfaces for Ultra-Wideband and Angularly Stable Polarization Conversion,"* Sci. Rep. 8:8628 (2018), DOI [10.1038/s41598-018-25934-3](https://doi.org/10.1038/s41598-018-25934-3), [PMC5955921](https://pmc.ncbi.nlm.nih.gov/articles/PMC5955921/), PubMed 29769556 — fetched and read directly, byline independently confirmed via PubMed, Nature/Scientific Reports, and the PMC page itself — states its fitness function verbatim as:

   > `Fit = Σ(n=1 to nf) |Rxx_i|² + |Ryy_i|²`

   a **sum of squared co-polarized reflection** across `nf = 21` discrete frequency samples — an energy/average-style objective, not a worst-case one. **This is a broadband linear-to-linear (90° rotation) polarization converter, not a linear-to-circular (axial-ratio) converter like Example 6** — its fitness function minimizes co-polarized reflection for both principal linear incident polarizations, a polarization-purity/rotation objective, structurally adjacent to but not identical with the axial-ratio question this document scores. It bears on the minimax-vs-sum question by device-family analogy, not as a direct precedent for AR optimization specifically.

**Honest verdict, in this project's own vocabulary:** `NO CONVENTION FOUND FOR AN IDENTICAL CASE — REASONED BY ANALOGY, NOT ADOPTED FROM A DIRECT CITATION.` Minimax is recommended for this project's *success score* (does the candidate meet a customer's band-wide AR requirement) on the strength of (a) the field's own definition of "AR bandwidth" as a threshold-everywhere quantity, (b) the identical structural argument ADR-0041 already made and verified for the sibling absorber family ("a single lucky deep point can't hide failure elsewhere in the band"), and (c) this project's own established practice of keeping a *search-time optimizer heuristic* (which can legitimately be a smooth, GA-friendly proxy like a sum-of-squares) distinct from a *success-criterion* (what decides pass/fail against the customer's actual ask) — the same separation already drawn between `CORRELATION` and `SIMULATION` mechanisms. But this is not claiming a paper does this identically for AR the way Yiğit & Duysak's explicit anti-averaging argument was verified for absorbers — that specific argument has not been made, in those words, for axial ratio anywhere this search reached, and the closest available counter-example is for a different device function (rotation, not axial-ratio conversion).

**Angle: discrete benchmark zones, not a continuous sliding scale — now independently confirmed for this exact structure class.** ADR-0047 already overturned the absorber family's original "continuous sliding scale over incidence angle" pick in favor of curvature-derived *discrete* zones, because every conformal-absorber paper checked reported discrete-angle retention statements even when a continuous sweep was sitting right there in the data. The same GA-optimized reflective polarization-converter paper above (Borgese, Costa, Genovesi, Monorchio & Manara 2018) reproduces this pattern independently, in a structure class one step closer to Example 6 than any absorber paper is:

> Angular performance is "validated post-optimization at discrete angles (θ = 1°, 11°, 21°, 30°, 40°)"

— essentially the same 10°-step benchmarking the patent itself uses (0°, 10°, 20°, 30°, 40° per #107 §4/§5). This is a genuine, independent literature confirmation that discrete-zone angle scoring, not continuous integration, is the right shape for this family too, not just an extrapolation from the absorber decision.

## 2. Default when the customer is silent

Using this project's own A/B/C/DESIGN taxonomy (`docs/requirement-derived-thresholds.md`):

| Quantity | Kind | Default when silent | Reversible? |
|---|---|---|---|
| **AR threshold** | C-as-default, but an unusually strong one | **3 dB.** Unlike absorption's genuinely inconsistent 70–99% field practice, 3 dB is close to a definitional constant of what "circularly polarized" means at all — every general source checked agrees, with only stated departures (2 dB tighter for high-isolation dual-CP links; 4 dB looser for wide-scan arrays, per general secondary-source synthesis, not independently verified against a primary spec in this pass). | Yes — overridden without argument by any customer-stated figure, exactly like the absorber default. |
| **Incidence-angle range/set `Θ`** | A (per-requirement / host-curvature input, per #107 §6.3: "nothing in the physics selects it") | **`Θ = {0°}` — normal incidence only.** Silence is permissive (#117): with no stated host curvature or scan requirement, the loop should not invent an obligation to hold up off-boresight. This mirrors the absorber family's own rule (ADR-0041 point 4: angle range is host-curvature-derived) applied to a family with no curvature stated at all. | Yes — any stated host radius, bend requirement, or scan angle immediately supersedes it. |
| **Angle-dependent threshold relaxation** (e.g. 3 dB at boresight, 4 dB at 40°, a real pattern in wide-scan-array practice per the general search synthesis above) | Not adopted by default | **Flat threshold at whatever AR ceiling applies, unchanged across `Θ`.** No primary source in this pass ties a specific relaxation schedule to this structure class, so inventing one would be exactly the "smuggled convention" `requirement-derived-thresholds.md` warns against. | The customer may state a looser ceiling at wider angles explicitly; the loop should not assume one. |
| **Sense of polarization (RHCP/LHCP)** | Not a threshold-default question at all — see below | — | — |

**Sense of polarization — refined, not just restated, from #107.** #107 flagged this as a per-family human input because "an axial-ratio objective... is sense-blind" — true, and confirmed again here: the standard AR formula above uses `|R_co|`, `|R_cross|`, and `cos(2δ)`, none of which carry the *sign* of the phase difference, so a design and its mirror image score identically. But this search found the mechanism that resolves the practical question:

> "For a desired RHCP..., the polarizer is rotated/oriented such that the longitudinal axis of the meander-lines... are approximately **+45 degrees** relative to the 'natural' polarization of the antenna aperture. This essentially 'activates' the polarizer such that it converts the intrinsic linear polarization... to RHCP. For a desired LHCP..., the polarizer is rotated/oriented such that the longitudinal axis of the meander-lines... are approximately **−45 degrees**..."
> — US Patent 11,088,463 B1 (Thinkom Solutions Inc.), *Realization and application of simultaneous circular polarization in switchable single polarization systems*, [Google Patents](https://patents.google.com/patent/US11088463) (verbatim, fetched directly)

Combined with the IEEE convention for which rotation counts as which sense — "a circularly or elliptically polarized wave for which the electric field vector, when viewed with the wave approaching the observer, rotates counter-clockwise... is right-handed" (IEEE Std 145; corroborated consistently across multiple independent secondary sources — Wikipedia, MATLAB's documented implementation, and two independent radio-astronomy papers on arXiv — the primary standard text itself is not freely available and was not read, the same "cited, not read" status this project already gives IEEE Std 1128 and IEEE Std 1597) — **sense is a deterministic, computable output of the geometry, not an undecidable physical unknown.** What genuinely stays a human input is only *which* sense the downstream application needs (a receiving antenna's own handedness, a satellite downlink's polarization plan) — a Kind-A requirement, structurally identical to "which incidence angle range matters" or "which band."

**Practical consequence for the recipe:** the loop should **compute and label** which sense each candidate produces (from the simulated field data plus the IEEE convention, applied to the *reflected* wave's own propagation direction — reflection reverses propagation direction relative to the incident wave, so the convention must be anchored to the outgoing wave, not the incoming one, a genuine sign-flip trap worth stating explicitly, structurally the same caution as ADR-0047's voltage-vs-power trap for Rozanov). Since mirroring the geometry (+45° ↔ −45°) flips the sense at essentially zero electromagnetic or manufacturing cost, a silent customer should get **both mirror-image candidates offered, labeled by sense**, not a guessed default — and a later-stated sense preference becomes a free filter over already-computed candidates, not a re-design.

## 3. Physical bound

**Re-confirmed, from primary sources fetched directly in this pass, not merely trusted from ADR-0047:**

> "More work is needed to extend these results to the problem of broadband maximization of reflection, establishing fundamental tradeoffs between bandwidth, thickness, and reflectance."
> — Abdelrahman & Monticone, *How thin and efficient can a metasurface reflector be? Universal bounds on reflection for any direction and polarization*, [arXiv:2208.05533](https://arxiv.org/abs/2208.05533) (verbatim, fetched and confirmed word-for-word against `docs/absorber-thickness-bandwidth-bound.md`'s existing citation)

This is a **single-frequency** thickness-vs-efficiency bound (their own words: derived from "single-frequency light-matter interactions constrained by energy conservation"), applicable to reflective structures, and its own authors state plainly that the broadband/bandwidth version does not yet exist. **This confirms, rather than merely repeats, #129's finding.**

**A second candidate checked and correctly excluded, also confirmed fresh:** Arbabi & Faraon's oft-cited 25% cap on single-layer polarization conversion efficiency —

> "A single transmissive metasurface cannot change the polarization with an efficiency more than 25%... the maximum efficiency of a single layer **reflective** metasurface can be **higher** if the light is impinging on the metasurface from the higher index material."
> — Arbabi & Faraon, *Fundamental limits of ultrathin metasurfaces*, Sci. Rep. 7:43722 (2017), [PMC5338019](https://pmc.ncbi.nlm.nih.gov/articles/PMC5338019/) (fetched and confirmed directly)

**Does not bind Example 6** — the 25% cap is explicitly a transmissive (two-port) result; Example 6 is ground-backed/one-port per #107's own classification, and the paper says so itself. Also narrowband/single-frequency, same as Abdelrahman & Monticone.

**A candidate checked carefully and rejected — flagged as a near-miss, and corrected here from an earlier, mistaken "genuinely new finding" claim:**

> "For a circularly polarized [lossless, reciprocal PEC-backed array], there appears to be a fundamental trade-off between polarization purity and impedance bandwidth."
> — Doane, Sertel & Volakis, *Bandwidth Limits for Lossless, Reciprocal PEC-backed Arrays of Arbitrary Polarization*, IEEE Trans. Antennas Propag. 62(5):2531–2542 (2014), [IEEE Xplore](https://ieeexplore.ieee.org/document/6754154/) — **IEEE-paywalled; not read directly, only via consistent abstract-level secondary sources (ResearchGate, Semantic Scholar).**

**Correction to how this citation was first framed:** an earlier draft of this document claimed this author trio "did not previously appear anywhere in this repo... so it is a genuinely new finding." That claim was checked and is false: `docs/absorber-thickness-bandwidth-bound.md` §2.1 ("Oblique incidence — the assumption most likely to bite a conformal skin") already cites the same three authors' 2013 precursor paper, *"Matching bandwidth limits for arrays backed by a conducting ground plane,"* IEEE Trans. Antennas Propag. 61(5), 2511–2518 (2013) — the direct one-year-earlier ancestor of the 2014 paper cited here, already flagged there as "IEEE, not retrieved." (A separate, unrelated Volakis paper — Koulouridis, Kiziltas, Zhou, Hansford & Volakis 2006 — also appears in `docs/flexible-high-permittivity-composites.md`, though that is a coincidental, different research line.) This is a first-contact-with-the-2014-arbitrary-polarization-extension, not a first-contact-with-this-author-trio — the two papers should be read as the same authors' bandwidth-limit program extended from a general PEC-backed array (2013) to arbitrary polarization specifically (2014), not as unrelated finds.

Restated with that correction: **"impedance bandwidth" here means a fed antenna array element's match to its own feed line**, i.e., how efficiently a *transmitting or receiving* array radiates or absorbs power from a feed network across frequency while holding its intended polarization. Example 6 has no feed at all: it is an unfed, passively illuminated scatterer whose whole job is to stay near-100% reflective (zero absorption into any feed) while rotating polarization. This is the same category of mismatch the absorber family already ran into with filter roll-off rate — real, quantitative, superficially on-topic, and scoring a different physical quantity (a fed structure's own power-transfer efficiency, not an unfed converter's conversion bandwidth). **The primary IEEE text could not be obtained to confirm this exclusion with full certainty** — the exclusion rests on the abstract's own framing ("antenna arrays," "impedance bandwidth"), not a verified read of the derivation's boundary conditions. This is named as a missing measurement, not glossed over: someone with IEEE Xplore access should read the actual paper (both the 2013 and 2014 versions, now that their relationship is established) before this exclusion is treated as final.

**No new bound is derived here.** Deriving a genuine sum-rule bound for an unfed, passive, polarization-converting reflector — combining the two-polarization-channel Fano-Bode treatment Doane/Sertel/Volakis applied to a *fed* array with the *unfed*-scatterer boundary conditions Rozanov and Abdelrahman-Monticone use — is an original electromagnetics research undertaking, not a literature-verification task, and attempting it here risks manufacturing exactly the kind of unverified physics this project has been burned by before. This stays a named research gap: **if this project ever wants a genuine bandwidth bound for polarization conversion, it does not exist yet in the literature and would need to be derived from scratch**, most plausibly by adapting Fano-Bode/Herglotz-function sum-rule machinery (Gustafsson & Sjöberg's own toolkit) to a two-channel, unfed reflector — that adaptation has, as far as this search found, never been published.

**What is recommended — an explicit extension of an *existing* result's *use*, clearly labeled as such, not a new bound:** apply Abdelrahman & Monticone's single-frequency thickness-vs-efficiency limit (their Eq. 11) **pointwise, at each frequency inside the candidate's required band**, as an "advise, never gate" diagnostic exactly matching ADR-0047's own rule for Rozanov — reporting, per frequency, how close the candidate's realized conversion efficiency comes to the theoretical ceiling for its own thickness at that frequency. This is not a bandwidth score and never prunes; it is informative context, symmetric with how the absorber family reports `η = d_R/d_actual`. **This specific multi-point application has not been published anywhere found in this search — it is this document's own proposal, built on an existing single-point result, and should be labeled exactly that way if implemented, not as an adopted convention.**

**Also recommended:** always report raw fractional AR-bandwidth (`FB_AR`, per tested angle, informative and unbounded) alongside the pass/fail — matching the absorber family's universal habit of never quoting a bandwidth number without accompanying context, and matching this project's own instinct that when no bound exists, an unbounded-but-informative metric is still worth surfacing rather than silently omitted.

| Family | Bound exists? | Applies to Example 6? |
|---|---|---|
| Absorbers (Rozanov) | Yes, bandwidth-vs-thickness | No — different function |
| Beam steering / AMC backscatter (Gustafsson & Sjöberg) | Yes, bandwidth-vs-thickness | No — different function |
| Polarization conversion, transmissive, single-layer (Arbabi & Faraon) | Yes, but single-frequency, and a *different port count* | **No** — Example 6 is reflective/one-port |
| Polarization conversion, reflective, single-frequency (Abdelrahman & Monticone) | Yes, single-frequency thickness-vs-efficiency only | **Partially** — usable as a pointwise diagnostic only, per above |
| Fed PEC-backed array, arbitrary polarization (Doane, Sertel & Volakis 2013/2014) | Possibly, but appears to bound a different physical quantity | **Rejected, unconfirmed** — near-miss, primary text unread, already in this project's citation history via its 2013 precursor |
| A genuine bandwidth-vs-thickness bound for reflective polarization conversion | **Does not exist in the literature, confirmed twice over** | — |

## 4. What remains a genuinely open judgment call or research gap

1. **Minimax-as-scoring-objective is reasoned by analogy, not literature-identical.** The one paper found with an explicit fitness function for a closely related device (Borgese, Costa, Genovesi, Monorchio & Manara 2018) uses a sum, not a max (§1), and that device is a linear-to-linear rotator, not a linear-to-circular converter. This project's own recommendation to minimax rests on the absorber-family precedent and the field's own bandwidth-reporting definition, both real, but neither is a direct AR-optimization citation using the word "maximum" or "worst-case" the way Yiğit & Duysak did for absorbers. Anyone implementing this should cite the *definitional* argument (how "AR bandwidth" is universally reported) plus the absorber-family analogy, stated as such — not a nonexistent "AR minimax paper."
2. **The Doane, Sertel & Volakis (2013/2014) exclusion is provisional.** Its abstract-level framing ("antenna arrays," "impedance bandwidth") strongly suggests a fed-array mismatch with Example 6's unfed-scatterer problem, but the primary IEEE text (either year) was not read. This should be re-checked by someone with IEEE Xplore access before the exclusion is treated as settled — named here as a missing measurement, not silently assumed away.
3. **Whether Example 6's FIG. 10D is a single continuous CP band (13–17 GHz) or two separate narrow AR minima (near 13.85 and 16.6 GHz) is unresolved — and it is load-bearing for this recipe.** #107 itself reads the scanned plot as dips "near" two frequencies without confirming whether AR stays ≤3 dB continuously between them. This directly determines what `[f_lo, f_hi]` means in §1's formula — one contiguous band, or two disjoint sub-bands each scored separately. #107's plot reading is not re-derived here (out of scope), but whoever implements this recipe needs that reading resolved first, not assumed.
4. **Example 6 has no measured ground truth at all — a real asymmetry with Example 3.** Example 3's reproduction target is Landy et al. 2008, an independently *measured* curve, which is why FSV (ADR-0041 point 5) has something concrete to validate against. Example 6's FIG. 10D is **SIMULATED only** (per #107 §4's own table) — the patent never measured it, and the companion permittivity research doc could not even identify the substrate used. If a reproduction/validation check is ever needed for Example 6, **FSV is still the right tool by the same reasoning** (oscillatory, resonance-shaped curves; RMS error over-penalizes small resonance shifts) — but there is no independently measured curve of *this specific design* to validate against, only different published designs (Zhang, Liu, Wan, Zhang, Liu, Yang & Cui 2019; Undrasi & Khairnar 2024) that would test the solver's general credibility on this *device class*, not a reproduction of Example 6 itself. This gap should stay visible, not get quietly filled by treating an unrelated paper's measured curve as if it were Example 6's ground truth.
5. **The θ=0°-only silent default is a project-internal consistency argument (from #117 plus the absorber-family precedent), not an independently found polarization-converter-specific convention.** No source in this search stated "absent a host, test polarization converters at normal incidence only" — it is this document's own extension of an existing project rule to a new family, labeled as such rather than presented as literature-supported.
6. **The IEEE Std 145 sense convention rests on secondary sources only.** The standard's primary text was not read (same status this project already gives IEEE Std 1128 and IEEE Std 1597) — the description here is corroborated across several independent secondary accounts that agree with each other, which is the evidentiary bar this project has used before for an unread primary standard, but it is not a firsthand reading.
7. **Examples 1/2's physical-bound gap is addressed separately** (`docs/example1-2-scoring-recipe.md`), not here.
