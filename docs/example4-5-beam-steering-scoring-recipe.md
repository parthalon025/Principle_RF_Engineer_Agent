# Scoring recipes for US12089385B2 Examples 4 & 5 — closing NYS1's beam-steering half

**Serves:** [#104](https://github.com/parthalon025/Principle_RF_Engineer_Agent/issues/104)'s wayfinder map, "Not yet specified" item 1.

**Scope check.** This builds directly on `docs/seven-example-design-unknowns.md` (§2–5, design variables and success-criterion shapes — not re-derived), `docs/adr/0047-the-loop-advises-against-a-physical-bound-never-gates-on-it.md` / `docs/absorber-thickness-bandwidth-bound.md` §7.1 (the existing Gustafsson–Sjöberg assignment and its own already-documented caveat), and `docs/adr/0041-absorber-score-is-worst-in-band-minimax-with-fsv-comparison.md` / `docs/absorber-scoring-decision-confirmation.md` (the Example 3 scoring recipe this is asked to match in shape). Example 4's unbuildable εr=100 host (`docs/flexible-high-permittivity-composites.md`) and Example 5's unsourced-but-real BST route are treated as already settled and are not re-litigated — only their scoring question is new work here.

**Direct answer to the question the task leads with**, before the per-example detail: **the loop scores against the customer's stated angle (Example 4: one angle; Example 5: a scan range), never the raw span of the phase-coverage curve.** The curve's own span (e.g., "≈0°→305°, not 360°") is a property of the *element*, not a customer requirement — in `docs/requirement-derived-thresholds.md`'s own taxonomy it is a **DESIGN** quantity, not a **LIMIT** or **SPEC**. Treating "curve span vs. 360°" as the pass/fail line would be the same mistake that document was written to catch — a number expressed in the design's own units (degrees of *curve*) standing in for a requirement nobody stated (degrees of *steering*, dB of *gain*). This is also independently supported by the physics and the literature (§Ex4.1, §Ex5.1 below): the loss a truncated phase-coverage curve produces is not a fixed property of the curve — it depends on which angle the customer actually asked for, and grows toward the edge of whatever scan range is requested.

## Example 4 — static cylindrical-hole reflectarray (excluded likely-permanently, scored anyway per the charter's "warn, never block")

### 1. Primary objective

**What gets computed**, using the patent's own symbols (`docs/seven-example-design-unknowns.md` §2, Example 4: hole radius `r` ∈ [0.2, 1] mm, period `s` = 2.125 mm) plus the requirement's stated aperture cell count `N` and wanted angle `θ_want`:

```
Ideal per-cell phase (progressive-phase / beam-tilt law — standard reflectarray design equation):
    φ_ideal(x_n) = wrap360[ −(2π/λ0)·x_n·sin(θ_want) ],   x_n = n·s,  n = 0…N−1

Achievable-phase curve (the Tier-B unit-cell output, FIG 8E): φ_ach(r), r ∈ [0.2, 1] mm,
    spanning the patent's own [φ_min, φ_max] ≈ [0°, 305°]

Per-cell design choice (a DESIGN quantity, not a threshold):
    r_n = argmin_r | φ_ach(r) − φ_ideal(x_n) |  (mod 360°)

Realized aperture field:      E_n = A_n · exp[j·φ_ach(r_n)]     (A_n = feed/illumination taper)
Realized array factor:        AF(θ) = Σ_n E_n · exp[j·k0·x_n·sinθ]

PRIMARY, customer-facing objective — gain/efficiency loss at the wanted angle, in dB:
    η(θ_want) = |AF(θ_want)|² / (Σ_n |E_n|)²
    Loss_dB = 10·log10[ η(θ_want) ]     (≤ 0 by construction: η ≤ 1, so this is
                                          reported as a negative number — "how far
                                          below perfect phasing," not a positive
                                          loss magnitude)
```

**Why there is no separate `η_ideal` term.** An earlier draft of this recipe divided by `η_ideal(θ_want)` — the same expression with `φ_ach(r_n)` replaced by the exact `φ_ideal(x_n)` — but that quantity is provably identically 1 by construction: at `θ=θ_want` the ideal phase law exactly cancels the array-factor phase term for every element, so `|AF_ideal(θ_want)| = Σ|E_n|` regardless of the amplitude taper `A_n`. Computing it was a tautology; `Loss_dB` collapses to `10·log10(η(θ_want))` directly, as written above, and this is what isolates the loss caused *specifically* by the curve's truncation (not ohmic loss, not feed taper — those are separate, already-modeled terms).

It is the direct generalization, to a continuous-but-truncated curve, of the **ΓEVM (error-vector-magnitude) approach**: Ke Peng, Kai Da Xu & Qiang Chen, *"Gain loss in metasurfaces caused by reflection-coefficient quantization: an error vector magnitude approach,"* Optics Express 34(1):726–742 (2026), DOI `10.1364/OE.580860` — "ΓEVM, for the complex reflection coefficient of a metasurface unit, [is] defined as the root-mean-square difference between the ideal and realizable reflection coefficients over [0, 2π) … enabling quantitative evaluation of the unit's quantization precision and prediction of the resulting gain loss in the entire array," with "a closed-form expression for ΓEVM … together with an empirical relation that relates ΓEVM to the gain loss." *(Confidence note: journal, volume, DOI and author list independently corroborated via WebSearch; the abstract's substance is consistent across the search results, but the primary PDF was not fetched and the exact closed-form/empirical relation was not independently read — same "cited, not read" bar this project already applies to, e.g., IEEE Std 1597.1.)*

**Why this aggregation (minimax-flavored, not mean) is right, and why it is not literally identical to the absorber's minimax.** For the absorber (ADR-0041), the *scored quantity itself* is a worst-of-many number (worst-absorbing frequency), because the requirement ("≥X dB everywhere in-band") is itself a worst-case requirement. Here the customer-facing primary quantity — gain loss at θ_want — is naturally a *single* number once θ_want is fixed, so there is no frequency-like axis to minimax *within* the primary objective for Example 4 specifically (its steering angle is singular, baked in at print time). The minimax *reasoning* from Yiğit & Duysak (2021, already quoted in ADR-0041 — "if the design has a very low reflection coefficient at any … frequency, it significantly reduces the average value and affects the general information about other values") still matters, but it applies one layer down, as an internal diagnostic: **do not average per-cell phase error across the aperture.** A handful of cells whose ideal phase falls in the ~55° gap the curve doesn't cover get clamped to the nearest edge, producing a *localized, deterministic* phase discontinuity — and a deterministic, spatially-clustered discontinuity seeds a **quantization/spurious lobe** at a predictable angle far more efficiently than the same total phase error spread randomly would.

There is a real, independently-reported mechanism behind this — stated plainly here at the confidence tier it actually has, corrected from an earlier overstated "confirmed": a WebSearch pass turned up matching characterizations ("quantization loss is up to 3 dB for a one-bit RRM and increases significantly as the steering angle increases," and mechanistically "quantization error … grows with beam steering angle, since larger steering angles require larger required phase gradients across the aperture") attributed to the reconfigurable-reflectarray/RIS literature (a ScienceDirect record, S1569441022000815). **Neither the ScienceDirect paper nor a specific companion arXiv derivation was independently fetched in this pass** — this is `LITERATURE-SUPPORTED at search-synthesis confidence`, not `CONFIRMED`, and should be read that way until someone fetches the primary text directly. The classical **Miller/Mailloux sinc² N-bit quantization-loss result** (Miller, *"Minimizing the effects of phase quantization errors in an electronically scanned array,"* Proc. 1964 Symp. Electronically Scanned Phased Arrays; Mailloux, *Phased Array Antenna Handbook*, Artech House, 2005 — cited via consistent secondary description across multiple independent sources, primary text not read, same evidentiary bar as ADR-0041's own Weile 1996 citation) is the deterministic-quantization analog of this same mechanism, giving ≈3.9 dB (1-bit) → 0.9 dB (2-bit) → 0.2 dB (3-bit) loss — useful as a sanity-check ceiling, though Example 4's curve is a *continuous truncation*, not a discrete N-bit quantization, so these numbers bound the phenomenon rather than apply directly.

**A directly on-point, verified (not just synthesized) primary source** confirms this whole picture at exactly this program's own band: a single-layer X-band (10 GHz) reflectarray paper, fetched directly, states the H-shaped-slot element "achieves a phase range greater than 480°" (vs. a plain patch) and that "factors limiting the overall efficiency include element losses, **phase quantization errors**, edge effects, and feed illumination," reporting 25.5 dBi gain at 63.7% aperture efficiency — *but does not quantify how much of that loss phase-range truncation alone causes* (PMC11434495, direct fetch confirmed the quote; no numeric breakdown exists in the paper). This is genuinely useful and genuinely incomplete evidence: it confirms phase-range truncation is a named, real efficiency driver at this exact band and element class, and it confirms nobody has published the clean decomposition this project would want to build.

**Separately reported, never blended into the primary number** (same discipline as ADR-0041 point 3's off-band score):
- **Beam-pointing error** (degrees): `θ_peak = argmax_θ |AF(θ)|²`, report `|θ_peak − θ_want|`. Gain loss and pointing error are physically distinct failure modes and blending them would hide which one is the actual problem.
- **Worst spurious/quantization-lobe level** (dB below main beam) and the direction it points. This is not a pure pass/fail threshold — like Example 7's "backscatter reduction... redirects, it doesn't absorb" finding already on the map (`docs/seven-example-design-unknowns.md` §6.3: *"a checkerboard does not absorb; it redirects... No solver can know that [where the redirected energy lands is acceptable]"*), a steered aperture's leftover quantization lobe is the same shape of problem — the loop can report where it points, but whether that direction is acceptable is a human judgment call, not a scoreable threshold.

### 2. Default when the customer is silent

**No default for the wanted steering angle, and none should be invented.** Unlike −10 dB/90% absorption (a near-universal reporting convention across a whole absorber literature, per ADR-0041 point 2), no comparable "typical ask" exists for a steering angle — reflectarray papers report whatever angle their specific application needs (0°–60°+), with no field-wide center of mass. Worse, the obvious candidate default, θ=0° (broadside), is **degenerate for this whole design family**: a plain conductor already reflects specularly at 0° with no phase-gradient pattern needed, so "default to broadside" would silently substitute a design that defeats the reason to build this element at all. Per `docs/requirement-derived-thresholds.md`'s own rule ("silence is permissive... no threshold, no pruning"), the honest behavior is: **silence leaves the beam-steering objective unscored/blocked**, not silently guessed, and surfaces back to the requirement author as a missing input — while the raw phase-coverage curve itself (span, monotonicity) can still be reported as an informational **DESIGN** characterization, never as a pass/fail.

The aperture size/cell count `N` has the identical status — already flagged in §6.3 of the design-unknowns document as a common per-family human input — and needs the same "no default" treatment here, since it directly sets how many cells' worth of the phase-coverage curve actually get exercised for a given angle.

### 3. Physical bound

**#129/ADR-0047's assignment (Gustafsson & Sjöberg) is legitimate for the axis it actually covers — and that axis is not the one Example 4's success criterion is stated on.** Read precisely (verbatim quotes already verified in `docs/absorber-thickness-bandwidth-bound.md` §7.1): Gustafsson & Sjöberg bound **fractional bandwidth** `B` — how much frequency range a *fixed-geometry* grounded surface can hold its reflection phase inside a window Φ, given thickness `d`: `Bλ₀/d ≤ 2.6` for Φ=π/2. That document's own honest caveat already says the quiet part: *"no retrieved source states a bound on beam-steering bandwidth as such (array factor, scan angle, aperture efficiency). Treat the element-level phase-stability bound as `LITERATURE-SUPPORTED` and the step to array-level steering bandwidth as `INFERRED`."*

Example 4's own stated criterion (§4/§5 of the design-unknowns doc: FIG 8E, phase **vs. hole radius `r` at one fixed frequency**) is swept on a **different axis entirely** — geometry, not frequency. Where G&S legitimately, directly applies to Example 4 is a genuinely useful but *different* question than the one #107 named: **once `r_n` per cell is fixed to synthesize θ_want at 10 GHz, how much can the operating frequency drift before Loss_dB grows unacceptably** — a real, correctly-scoped bandwidth check, worth keeping, but not an answer to "why does the curve stop at 305° instead of 360°."

**That second question — how much of a 360° phase circle a *bounded geometric-parameter sweep* can access at one frequency — has no bound assigned to it in #129's table, and no literature source for it was found either.** Two honest paths forward, kept clearly separate from each other and from the adopted G&S assignment:

- **A concrete, checkable lead already sitting in this project's own citation list, currently pointed at the wrong example.** Abdelrahman & Monticone, *"How thin and efficient can a metasurface reflector be? Universal bounds on reflection for **any direction** and polarization,"* [arXiv:2208.05533](https://arxiv.org/abs/2208.05533) — quoted verbatim in `docs/absorber-thickness-bandwidth-bound.md` §7.2 — is a **single-frequency**, energy-conservation/passivity bound ("the only assumptions are that the structure is passive, with a surface area much larger than its thickness, and is made of a single local, isotropic, and nonmagnetic material"). #129/ADR-0047 cites it only for Example 6 (polarization conversion). But its own title says "any direction," and a single-frequency thickness-vs-efficiency bound on redirecting reflection to an arbitrary direction is *structurally* the right shape of bound for "how much phase/redirection performance can a thin sheet deliver at one frequency" — which is exactly Example 4's stated criterion, and arguably a better-fitting candidate than the bandwidth-shaped G&S sum rule that got assigned instead. **This was not checked when #129 resolved** (that ticket's own framing was "is Example 3 near a thickness-bandwidth limit," which steered the search toward sum-rule-shaped bounds and away from single-frequency ones). This is flagged explicitly as an unresolved, concrete, well-scoped next step — not a settled result.
- **A plausible but unverified physical argument, offered only as a labeled sketch, not a bound.** A single-resonance, lossless, ground-backed unit cell's reflection phase is, in Foster-reactance terms, a function of a generalized reactance that can range over (−∞, +∞) as the resonance is fully detuned in either direction; sweeping it over the *entire* real line in principle recovers the full 360°. A **finite** geometric range (`r` from 0.2 to 1 mm) only accesses whatever finite sub-arc of that reactance curve the range reaches — which is a plausible mechanistic explanation for why the patent's own curve falls ~55° short. **No source states this as a formal, citable bound relating a finite parameter-sweep range to accessible phase span** — it is offered here as a candidate direction for a **new** derivation, explicitly not adopted, not verified, and not to be cited as literature-supported.

### 4. Genuinely open judgment call / research gap

- **Whether FSV (ADR-0041 point 5) extends to a phase-vs-geometric-parameter curve is unsettled, and defaulting to it here would be exactly the kind of unchecked convention-import this project has been burned by before.** FSV's stated justification is that naive RMS "over-penalizes... a small resonance-frequency shift" in "oscillatory, resonance-shaped EM data" (ADR-0041 point 5). Example 4's phase-vs-`r` curve, per its own description, is a smoother, more monotonic S-curve over a swept geometric parameter — not a sharp resonance swept in frequency. Whether that specific failure mode (and therefore FSV's specific advantage) is even present here has not been checked, and should be, before any reproduction-comparison mechanism is built for this family. A simpler percent-difference-at-matched-parameter-points metric (already named as option 2 in `docs/absorber-scoring-decision-confirmation.md` §5.4) may be entirely adequate for a monotonic curve — this is not decided here.
- **No reproduction target currently exists to compare against anyway.** Example 4 is excluded likely-permanently (unbuildable host), so this whole recipe is presently unexercisable on real hardware — consistent with the charter's "warn, never block": the loop still hands back the candidate, scored, with the material gap named, rather than silently dropping it. If a host material is ever found, the target curve would be the patent's own FIG 8E (already digitized per `docs/seven-example-design-unknowns.md`); whether an independent, externally-published original of this specific element exists was not checked in this pass and is a concrete, bounded follow-up, out of this task's scope.
- **The EVM/Optics Express citation is abstract-level, not full-text-verified** — its exact closed-form ΓEVM-to-gain-loss relation has not been independently read, and should be before it is wired into code as more than a design sketch.
- No paper decomposes an X-band reflectarray's efficiency loss into "this much from phase truncation, this much from feed/ohmic/edge" (PMC11434495 names phase quantization as a factor but gives no split) — so the PRIMARY objective formula above (`Loss_dB`) is this project's own construction from the ΓEVM idea, not a lift of a published formula; it should be labeled as such, not as an adopted convention.

## Example 5 — BST-tunable reflectarray (excluded-for-now, revisable per #108)

### 1. Primary objective

**The structural difference from Example 4 changes the shape of the objective, not just its inputs.** Example 4 is a *static* design: one `r` per cell, chosen once, fixed forever, for one beam direction. Example 5 is *reconfigurable*: every cell has the same fixed patch geometry (`l` = 4 mm), and a per-cell bias voltage retunes `ε1` — and hence phase — in real time (`docs/seven-example-design-unknowns.md` §2, §5). **If a customer only ever wanted one fixed angle, they would not need this tunability at all** — a static equivalent (Example 4, if buildable) would be simpler and cheaper. So Example 5's "wanted steering angle" input is naturally a **scan range** `Θ = [θ_min, θ_max]` (or a discrete commanded-angle set), not a single value, and the per-cell design choice — which `ε1,n` (bias `V_n`) each cell gets — is **recomputed per commanded angle**, using the same nearest-achievable-phase lookup as Example 4 but against `φ_ach(ε1)` instead of `φ_ach(r)`.

```
Per commanded angle θ ∈ Θ:
    φ_ideal(x_n; θ) = wrap360[ −(2π/λ0)·x_n·sinθ ]
    ε1,n(θ) = argmin_{ε1∈[3.5,5.0]} | φ_ach(ε1) − φ_ideal(x_n; θ) |
    Loss_dB(θ) computed exactly as in Example 4, from the resulting AF(θ)

PRIMARY objective (minimax over the customer's scan range, not a single-angle or mean value):
    Loss_dB,worst = max_{θ ∈ Θ} Loss_dB(θ)
```

**Why minimax over scan angle, and why this is a reasoned extension rather than a directly-confirmed citation.** Two independent, converging lines of evidence support scoring the *worst* angle in the range, not the mean:
1. **ADR-0041's own argument, applied to a new axis by direct analogy.** Yiğit & Duysak's argument against averaging ("a very low reflection coefficient at any... frequency... significantly reduces the average value") applies verbatim if "frequency" is replaced with "scan angle": an easily-served angle in the middle of the range cannot compensate for a badly-served one at the edge, and a customer asking for "±30° coverage" needs the worst angle in that range to work, not the average.
2. **An independently-confirmed, real reporting convention in phased-array engineering**: "scan loss" is reported at the *edge of scan* as a matter of course — e.g. "scan loss... to ±60 degrees" and cos^n(θ) roll-off models quoted directly at the maximum specified angle (WebSearch synthesis of multiple issued antenna patents; secondary-source confidence, not peer-reviewed literature, but internally consistent across independent sources). This is corroborated by the mechanistic finding already cited for Example 4 — quantization/truncation loss "increases significantly as the steering angle increases" — meaning the edge of the scan range is *generically* also the hardest point for the curve to serve, though this should be **computed, not assumed**, since the achievable-phase curve's own irregularities could make a mid-range angle the actual worst case for a specific cell layout.

**The single most directly relevant, band-matched primary source for Example 5 — corrected from an earlier draft that missed it in favor of a Ka-band precedent:**

> "An overall phase range of 298 degrees and 263 degrees with maximum reflection losses of 16 and 8.8 dB at Ka- and X-bands, respectively, are measured when the unit cells are operated for maximum phase range… a phase range of 250 degrees with maximum reflection losses of 5.6 and 5.8 dB at 30.7 and 10.27 GHz are achieved."
> — Karnati, K. K., Shen, Y., Trampler, M. E., Ebadi, S., Wahid, P. F. & Gong, X., *"A BST-Integrated Capacitively Loaded Patch for Ka- and X-band Beamsteerable Reflectarray Antennas in Satellite Communications,"* **IEEE Trans. Antennas Propag. 63(4), 1324–1333 (2015)**, DOI [10.1109/TAP.2015.2389252](https://doi.org/10.1109/TAP.2015.2389252) — quoted verbatim from a directly-fetched summary of the primary IEEE record.

This is a real, measured, BST-loaded-patch element with **X-band data at 10.27 GHz** — inside Example 5's actual 10–20 GHz operating range (`docs/seven-example-design-unknowns.md` §4, FIG 9D), structurally the same device as the patent's own (a self-phased patch over a bias-tuned ferroelectric layer, metal-backed). It states outright that **phase range and reflection loss trade against each other at the same operating point** (263° costs 8.8 dB at X-band; a reduced-range 250° operating point at a nearby X-band frequency costs only 5.8 dB). This directly validates something `seven-example-design-unknowns.md` §6.3 already listed as a per-family human input ("phase range vs loss for #4/#5") and sharpens it into a scoring consequence: **the objective above cannot score phase-match error alone** — a cell chosen to hit its required phase near the edge of the arc, where loss spikes, should be penalized for that loss even if its phase is exact. **The primary objective should therefore, in a future refinement, be a joint quantity — phase-error-weighted by, or reported alongside, the achieved reflection magnitude at each selected operating point — not `Loss_dB` from array-factor phasing alone.** No formula for combining the two into one scalar is proposed here; that is a genuinely open design question for whoever implements this.

**A second, Ka-band-only source, now correctly caveated rather than presented as the closest precedent:** Karnati, *"Beam-Steerable and Reconfigurable Reflectarray Antennas for High Gain Space Applications,"* UCF dissertation (open access, [stars.library.ucf.edu/etd/1488](https://stars.library.ucf.edu/etd/1488)) — fetched directly and confirmed to report a 45-element BST-loaded array measured to "a beam scan up to 25°" in anechoic-chamber far-field patterns. **This is a Ka-band demonstration (~26–40 GHz, per the dissertation and the group's companion IEEE papers), not Example 5's actual 10–20 GHz band** — a real band mismatch that must travel with this citation rather than being silently read as "the closest real precedent," the same "measurement without its box" failure mode `docs/RUNNING-LISTS.md`'s corrections repeatedly call out. Its abstract does not expose a scoring formula, and the full PDF's text layer was not machine-readable in this environment. The **Karnati/Trampler/Gong 2015 TAP paper above is the better-fitting, band-matched precedent** and should be treated as the primary Example-5 data point; the dissertation is retained here only as a secondary, Ka-band data point on the same research group's device family.

**The frequency axis (FIG 9D) is a genuinely separate, secondary check — and here Gustafsson & Sjöberg fits far more natively than it does for Example 4** (see §3 below).

**Separately reported**, same as Example 4: beam-pointing error per commanded angle, and worst spurious/quantization-lobe level and direction (with the same "no solver can know if that direction is acceptable" caveat as Example 7's redirected-energy problem).

### 2. Default when the customer is silent

Same conclusion as Example 4, for the same reasons: **no default steering angle/scan range, and none invented** — silence blocks the objective and is surfaced, not guessed. Two items are specific to Example 5 and get the identical "no default, must be stated" treatment, already flagged as per-family human inputs in `docs/seven-example-design-unknowns.md` §6.3:
- **The available bias supply and per-cell control wiring budget** — a systems-engineering/power-budget constraint, not a physics constant, with no literature convention to fall back on.
- **How much of the ε1 = 3.5–5.0 sweep gets used per cell** is a **DESIGN** output the solver is free to choose to hit the objective (analogous to `r_n` in Example 4) — never a threshold, and there is no reason to expect or invent a "typical fraction of the sweep" convention.

### 3. Physical bound

**Same base assignment as Example 4 (#129/ADR-0047: Gustafsson & Sjöberg), but it fits Example 5 more directly — and this is a real difference between the two examples worth stating plainly, not glossing over.** Example 5's own reported performance curve (FIG 9D) is phase **vs. frequency** at fixed `ε1` — literally Gustafsson & Sjöberg's native axis (`Bλ₀/d ≤ 2.6` for a ±45° phase window), unlike Example 4's Fig 8E (phase vs. a geometric parameter at one frequency, an axis G&S does not bound at all). So: **for Example 5, G&S legitimately and directly scores the secondary/bandwidth question** — once a bias state is chosen for whichever commanded angle, how much frequency excursion around 10 GHz keeps `Loss_dB(θ)` acceptable — with less of an inferential leap than Example 4 needed.

**The same underlying gap remains for the primary, angle-enabling axis.** Bounding phase-stability-vs-frequency at fixed `ε1` says nothing about how much of the phase circle the `ε1 = 3.5→5.0` sweep can access at any *one* frequency — the actual beam-steering-enabling mechanism. The same Foster-reactance-style physical argument sketched for Example 4 (a finite tuning range of a resonance-detuning parameter accesses only a finite arc of the full phase circle) plausibly still applies here, since biasing `ε1` shifts the patch's effective resonant frequency by the same underlying mechanism as varying the hole radius does — but this is, again, an unverified, labeled-as-new sketch, not an adopted bound. The same Abdelrahman & Monticone "any direction," single-frequency, thickness-vs-efficiency bound flagged as an unchecked, concretely actionable lead for Example 4 applies with equal or greater force here, and — per this project's ADR-0044 ("material is a variable, material properties are the constant") — would need to be evaluated with BST's own loss tangent as an input, which `docs/seven-example-design-unknowns.md` §3 already flags as `UNKNOWN` for this example ("Ferroelectric loss at X-band is the usual reason tunable reflectarrays underperform; its absence is a real gap"). Now that Karnati/Trampler/Gong (2015) has surfaced a real, measured X-band reflection-loss figure for a structurally similar BST patch (8.8 dB at 10.27 GHz, at the maximum-phase-range operating point), that is a candidate first real data point for this gap — not a resolution of it, since it is measured on a different specific unit cell than the patent's own.

### 4. Genuinely open judgment call / research gap

- **The scan-range-minimax recommendation is a reasoned analogy, not a confirmed literature import** — stated plainly in §1 above, not smoothed over.
- **The joint phase-error/reflection-loss objective flagged in §1 is a real refinement this pass argues for, but does not fully specify** — no formula for combining the two into one scalar is proposed here; that is left as an open design question for whoever implements this.
- **The Karnati UCF dissertation is a secondary, band-mismatched (Ka-band) data point, not the primary Example-5 precedent** — corrected in §1 above from an earlier framing that presented it as the closest available source without that caveat. Its PDF's text layer did not extract cleanly in this environment (the same category of extraction failure `docs/absorber-scoring-decision-confirmation.md` §6 already logged for several other sources); whether it independently reports a phase-range number or a scoring formula beyond its abstract is unresolved and worth a second extraction attempt if the Ka-band caveat is ever found not to matter for a specific requirement.
- **Whether Abdelrahman & Monticone's "any direction" bound actually extends to anomalous/steered reflection, or only to the near-normal cross-polarization case it was worked out for**, has not been checked by reading the paper itself — flagged in both examples' §3, not resolved here.
- **BST loss tangent at X-band remains `UNKNOWN`** at the level of the patent's own specific unit cell (carried forward from `docs/seven-example-design-unknowns.md` §3, not re-derived), even though Karnati/Trampler/Gong (2015) now supplies a real, measured X-band reflection-loss figure for a structurally similar device — the scoring recipe is only as good as an input this project has already, correctly, flagged as missing for the patent's own geometry specifically.
- **Whether FSV or a simpler metric is right for comparing a reproduced phase-vs-ε1 curve against a published one** carries the identical open status as Example 4's §4 — not re-argued, same unresolved question, same honest "unsettled" label rather than a default assumption that ADR-0041's Example-3 choice simply carries over.
