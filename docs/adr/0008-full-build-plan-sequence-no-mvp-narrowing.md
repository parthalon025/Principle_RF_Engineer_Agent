# Build the full BUILD_PLAN.md sequence in strict phase order, not a narrowed MVP

**Context**: Scoping near-term work, a narrowed MVP was proposed and grilled with the user — calculation + knowledge only, evaluating designs against physical test data instead of running simulation, deferring Phases 6+ (NEC2++/openEMS/HFSS/measurement/correlation/optimization) indefinitely.

**Decision**: Reject the narrowed MVP. Build `docs/BUILD_PLAN.md`'s phases in full, in strict order — each phase (including its currently-incomplete pieces) finishes before the next phase starts. Phase 1 is expanded beyond its original generic list to also include antenna-synthesis calculations specific to this repo's actual domain (conformal/metamaterial antennas for QPS's EM3 division — see CONTEXT.md's Adaptive EM skin / Conformal antenna / Metamaterial unit cell entries): effective permittivity/resonant-frequency calculation, metamaterial unit-cell effective-medium parameters, fractional bandwidth ↔ Q, curvature-induced resonance shift, and aperture-gain estimate.

**Considered options**: The narrowed MVP would have been usable sooner (it only needed the already-built calculation, Touchstone-extrema, and knowledge tools) and was explicitly designed to avoid the large unbuilt simulation/measurement infrastructure. It was rejected in favor of executing the original plan in full — Phase 1 is treated as a blocking prerequisite for later phases, consistent with the project's own principle that "no model-generated numerical result is authoritative when a deterministic function can produce it."
