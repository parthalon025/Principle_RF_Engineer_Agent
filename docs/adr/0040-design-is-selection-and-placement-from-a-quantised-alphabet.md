# A design family declares a symbol alphabet, and design becomes selection and placement from a quantised set

Ticket #130, part of issue #104's wayfinder map, proposed that a design family may declare a **symbol alphabet** — a finite, characterised set of printed elements — so that a design becomes *choosing symbols and placing them* rather than tuning continuous dimensions, following the patent's own Example 7 (a two-tile checkerboard whose out-of-phase reflections scatter a return sideways instead of back). The ticket built directly on #131's prior-art survey, which settled that this is standard reflectarray practice and not a new architecture — element libraries have tabulated element-dimension-to-reflection-phase since the 1990s by solving one tile inside an infinite array of copies of itself — and that Marcuvitz's practice of publishing an error bound and a stated validity range for every table entry is "the most transferable idea in the survey," worth adopting whether or not the rest of the alphabet idea survived.

#131 also left two genuine gaps with nothing to inherit. First, whether a symbol should be a discrete, quantised set or a continuously tunable parameter: the field's own norm is continuous — Costanzo, Venneri, Borgia & Di Massa (*IJAP* 2019, DOI 10.1155/2019/9479010) tune a fractal scaling factor `S` continuously from 0 to 0.45 against a published phase-versus-`S` curve. Second, how large a block of identical symbols must be to keep the local-periodicity assumption from breaking at unlike-neighbour boundaries: across the survey, block sizes run 2 to 49 elements, set by beam geometry, control-line count, fabrication tolerance or compute cost — Cui et al. (*LSA* **3**, e218) fixes super-cell pitch at one wavelength because that sets the scattering angle, not because of coupling — and **none of them is an error budget**. #130 had to derive its own sizing rule rather than borrow one, published in full at `docs/supercell-sizing-rule.md`. The companion paper, Costanzo, Venneri & Di Massa (*IJAP* 2019, DOI 10.1155/2019/4890710), supplied the quantitative anchor for both questions: tuning a shape from its interior rather than its perimeter keeps the outline fixed, so the gap to a neighbour never moves, and the worst-case unlike-neighbour reflection-phase error (`Δφ_max`) it measures runs 12°/21°/25° at 0.5λ pitch and 20°/45°/85° at 0.4λ pitch across fixed-edge-interior-tuned, Minkowski-fractal and variable-size-square-patch families respectively (Table 3, Figs. 5–7).

Two further threads run through the record. The sizing rule's first pass, decided the same day, borrowed a ±22.5° phase-quantisation budget from beam-forming practice and a picked 30° minimum scattering angle, and concluded from them that block size was pinned to N = 2 and that three of six element families surveyed had no feasible block size at all; both borrowed constants were corrected before the document merged (see Corrections). Separately, one of the ticket's four stated reasons for adopting an alphabet at all — that a broadband super-cell "may buy bandwidth that thickness cannot," the case for a Tier A block — was challenged by #128's circuit bench and remains open on #187.

## Decision

1. **What a symbol carries.** Geometry and its tuning parameter; characterised response (reflection magnitude `|Γ|` and phase `∠Γ` versus frequency across the family's band); a **provenance rung per quantity**, not one rung for the whole record; and a **validity box** (Marcuvitz's practice) naming the conditions the numbers hold under — pitch, substrate, ink, pass count, cure schedule, incidence-angle range, and the neighbour set it was characterised against. `Δφ_max`, the worst-case unlike-neighbour phase error, is not one of these per-symbol fields: it is a property of **the alphabet at a pitch**, measured once by simulating a cell among its own kind and again with its two strongest-coupling neighbours swapped for the alphabet's extremes, and it belongs on the alphabet's own record.

2. **Characterise on a continuous parameter; admit only a quantised set as letters.** The continuous curve is not optional — it is how `Δφ_max` itself gets measured — but the admitted alphabet is the quantised set, because that buys **admission-by-printability and pre-measurability**. This is a **deliberate deviation from field norm**: established practice is continuous, with a tabulated curve (Costanzo's `S` from 0 to 0.45). A letter that has been physically printed and measured is worth more here than the expressiveness a continuous parameter would add — that is this programme's trade, not the field's.

3. **The optimiser becomes combinatorial selection and placement.** The search changes from continuous dimension-tuning to choosing which symbol occupies which block, block size set by the sizing rule below. **Genetic is the fit, confirmed rather than assumed** — it is what the coding-metasurface literature itself uses.

4. **Tier A families get no alphabet.** Example 3 is one cell repeated, with no unlike neighbours; an alphabet earns nothing there, and giving the anchor architecture a mechanism it does not use is how seams get designed wrong. The one Tier A construction that does want a block — several detuned resonators in a single super-cell, to widen an absorber's band (#110/#129) — is governed by different rules (below) and is modelled as its own thing, not as a coding alphabet with the steering switched off.

5. **The super-cell sizing rule is a function of the requirement, not a constant.** A coded surface reduces RCS by **cancellation**: two block types reflect out of phase and the returns subtract, so a phase error `δ` leaves a surviving echo of amplitude `sin(δ/2)`:

   ```
   RCS reduction (dB) = 20 · log₁₀( sin(δ/2) )
   δ_budget            = 2 · arcsin( 10^(−RCSR_dB/20) )
   ```

   giving a **floor** of 36.9° at a 10 dB requirement — reproducing the chessboard literature's own "180° ± 37°" rule of thumb, confirmed against Haji-Ahmadi, Nayyeri, Soleimani & Ramahi (*Sci. Rep.* **7**:11437, 2017), who state *"a phase difference of 180 ± 37° … provides at least 10 dB monostatic RCS reduction."* The **ceiling** is that the redirected lobe must clear the panel's own specular lobe, half-width ≈ `λ/(2L)` for an aperture of side `L` — so **the coupon is the hard case and a full-size part is easier** (4.8° at 6λ versus 0.95° at 30λ).

   **This headline is contradicted for coupon-sized parts and must not be quoted without a part size attached** — see the 2026-09-06 Correction below.

   For a **non-square cell** the rule carries an additional **panel-fit constraint**, `2·Nx·px ≤ L` and `2·Ny·py ≤ L` (reducing to `2·N·p ≤ L` on a square cell), and this constraint binds first on a coupon. On Example 3's actual 4.2 × 12 mm cell (0.14λ × 0.40λ at 10 GHz, aspect ratio 2.86), every block up to 4×2 is **evanescent and redirects nothing**; **5×2 is the smallest block that radiates at all** (71.5°). Because larger blocks are physically forced on this cell, the block **genuinely averages** — the opposite of the square-cell result, where the smallest admissible block (N = 2) touches a foreign neighbour on every one of its cells and averages nothing.

## Considered and rejected

- **A fully continuous alphabet, matching field norm.** Costanzo, Venneri, Borgia & Di Massa's continuously tunable fractal scaling factor is the established practice. Rejected as the alphabet's *admitted* shape — kept only as the characterisation method that produces `Δφ_max` — because a discrete letter that has actually been printed and measured is what this programme trades expressiveness for.
- **Borrowing a literature convention for block size.** Every source #131 surveyed sets block size by beam geometry, control-line count, fabrication tolerance or compute cost; Cui et al. fixes pitch at one wavelength for scattering-angle reasons alone and discusses no unlike-neighbour coupling at all. Rejected because none of them is an error budget — the rule had to be derived from the surface's own cancellation mechanism instead.
- **Scaling block size up as the universal answer to coupling error.** Correct for beam-forming, where a large aperture is wanted anyway and every inherited block-size rationale comes from that world. Backwards here: the ceiling (the redirected lobe clearing the panel's own specular return) collapses far faster than the floor relaxes, so a coding surface runs out of room to grow a block long before coupling error would justify one.
- **A multi-level phase gradient**, considered as an escape when a block-size window came up empty. Rejected as relocating the coupling problem rather than escaping it — Costanzo's own multi-level design measured 0.75 dB of gain loss and up to 6.6 dB of sidelobe violation from the same mechanism.
- **An alphabet for every Tier A family.** Rejected beyond the one construction that actually needs a block; Example 3 has no unlike neighbours for an alphabet to help with.

## Consequences

- **Unblocks #109** (what a design family declares): an alphabet is one of the things a family may declare, and it carries `Δφ_max` and a validity box alongside its letters.
- **The sizing rule's two scopes must not be conflated.** It governs coding metasurfaces (Example-7-like Tier B families) only. The broadband super-cell (#110/#129) steers nothing, so the §5 ceiling does not apply to it at all — only the floor's opposite pressure does, and it is sized as large as useful rather than as small as a redirection angle allows. Same word, opposite sizing pressure.
- **#138 is the direct follow-on**, testing the patent's own I-shaped ring resonators against the interior-tuning criterion this ADR treats as a strong, quantified preference rather than an absolute gate — the characterise-then-gate pipeline this ADR sets up working as intended. Its answer is conditional, not a clean pass or import: the ring's own interior split-gap `G` clears the gate outright (1.0× gap excursion versus the square patch's 21.1×), but the patent's own published tuning strategy uses a *different* knob (the cut wire, an E-plane perimeter parameter measuring 20.7×) that reproduces the square patch's exact problem — so which knob an alphabet actually uses matters, and using the patent's own strategy would fail this ADR's gate despite the element itself passing it. Left genuinely open by #138, not resolved: whether the cut wire's own separate, equally tight E-plane gap dominates the coupling error regardless of which knob is chosen for tuning — settling this needs Costanzo's protocol run on both cell axes, still waiting on the unit-cell simulation setup (#104). Withayachumnankul, Fumeaux & Abbott's interdigital-capacitor ELCs (2.10–3.14 GHz at an identical 14 mm cell, zero gap excursion) are named only as a fixed-outline fallback *if* `G`-tuning proves insufficient — not an import already made.
- **The alphabet library's admission pipeline, re-characterisation and process identity are left thin here** and are settled later, in ADR-0027: admission requires printing, not simulation; entries never expire, they stop matching; and the process (machine, ink, cure) is a first-class referenced object, distinct from the validity box this ADR defines.
- **Open and unresolved: whether the broadband-bandwidth rationale survives.** One of this ticket's four stated reasons to adopt an alphabet at all was that a broadband super-cell "may buy bandwidth that thickness cannot." #128's circuit bench found otherwise: on a single shared spacer over one ground plane, four detuned letters bought only **0.7 percentage points** of ≥90%-absorption bandwidth (22.1% → 22.8%), consistent with a model in which every cell shares one inductance and detuning only varies capacitance — averaging toward one resonance rather than creating a second. This directly challenges the fourth rationale and is **still open on #187**; the other three (fast evaluation, `MEASURED` provenance, manufacturability-by-construction) are untouched either way. Three follow-up checks (`docs/five-paper-absorber-corpus-findings.md`, `docs/supercell-ring-inductance-bench.md`, `docs/patch-q-factor-bound-primary-source.md`) have since narrowed but **not settled** the question, specifically whether inter-cell coupling — the term the shared-inductance circuit model omits — changes the answer. This ADR does not resolve it.

## Corrections

### 2026-09-04 — the sizing budget was borrowed from beam-forming, not derived from the surface's own cancellation mechanism

**What this ADR originally said:** the first pass at the super-cell sizing rule adopted a **±22.5°** phase-error budget (the half-step of a 3-bit beam-forming phase-quantisation convention) and a **picked** 30° minimum scattering angle, and concluded from them that block size was pinned to **N = 2**, that grouping "does not rescue an alphabet that fails" the budget, and that **three of six element families surveyed — including the variable-size square patch, "the workhorse of the entire reflectarray field" — had no feasible block size at all.** The interior-tuning criterion was, on this basis, promoted from a preference to a hard admission gate.

**Why it was wrong.** ±22.5° keeps quantisation lobes acceptable when *steering a beam*; this surface does not steer a beam, it cancels a return — exactly the trap `docs/RUNNING-LISTS.md` §3 item 13 had already recorded: phase quantisation "is well characterised — only for beam-forming. Not for absorption or backscatter reduction, which is what this effort actually optimises." The 30° minimum scattering angle was picked, not derived from anything. Together the two borrowed constants made the rule roughly six times stricter than the objective warranted.

**What is true instead.** Derived from the surface's own cancellation mechanism: a phase error `δ` leaves a surviving echo `sin(δ/2)`, so `RCS reduction (dB) = 20·log₁₀(sin(δ/2))` and, inverted, `δ_budget = 2·arcsin(10^(−RCSR_dB/20))` — **36.9°** (36.87° unrounded) at a 10 dB requirement, agreeing with Haji-Ahmadi et al.'s independently published "180 ± 37°" rule to **0.13°**. The ceiling is that the redirected lobe must clear the panel's own specular lobe, `≈ λ/(2L)` — **4.8°** on a 6λ coupon, not 30°. At a 10 dB requirement every element family surveyed is feasible **on a full-size part**, including the variable-size square patch — but see the 2026-09-06 correction below for why that headline does not hold on a coupon. Interior tuning is downgraded from a hard gate to a strong, quantified preference: it buys **headroom and spatial resolution** — N = 2 against N = 9 at 10 dB for the square patch, four and a half times finer control over the surface — and becomes decisive again only at demanding reduction levels (at 20 dB, the 0.4λ square patch has no feasible block size on a 6λ coupon).

**This is an amendment, not a supersede (ADR-0020):** every other decision this ticket made — what a symbol carries, the validity box, characterise-continuous/admit-quantised, the combinatorial optimiser, no alphabet for Tier A — stands unchanged. Only the sizing sub-decision moves, from a fixed admission gate to a per-requirement sliding scale.

### 2026-09-06 — "every element family surveyed is feasible" is a claim about a part size, and was being carried without one

**What the correction above said, without qualification:** *"At a 10 dB requirement every element family surveyed is feasible, including the variable-size square patch."*

**Why that is not simply true.** #138, testing this rule against the patent's own I-shaped ring resonator, found that a 0.4λ square patch has **no feasible N on a 6λ coupon even at 10 dB** — feasible only on a panel around **30λ**. The cause is the panel-fit constraint from Decision point 5 (`2·N·p ≤ L`), which **binds first on a coupon**: a coupon-sized part hits the ceiling before it can grow a block large enough to clear the floor, exactly the "smallest radiating block is 5×2, and the block genuinely averages" mechanism this ADR's own Decision point 5 already describes for Example 3's own asymmetric cell. Restating the headline without naming a part size repeats the identical mistake this same document's first correction (above) exists to fix — a borrowed or omitted constant standing in for a number the requirement, or in this case the *panel*, actually determines.

**What is true instead, stated with its part size attached.** "Every element family surveyed is feasible at a 10 dB requirement" is true **on a full-size part** (≳30λ, per the square-patch case) and **false on a 6λ coupon** for at least the variable-size square patch. Feasibility is a statement about a `(family, requirement, panel size)` triple, never about the family and requirement alone.

**Not settled here — carried forward as a live, named inconsistency, per #104's own rule against laundering one.** Which other surveyed families share the square patch's coupon-infeasibility, and what the coupon's own effective admission gate looks like once panel size is a variable, is unresolved. `RUNNING-LISTS.md` §3 correction 38 records that the map itself once repeated the unqualified headline after already stating the qualifying mechanism in the same breath — the same failure this correction exists to close off for good.

**This is an amendment, not a supersede (ADR-0020):** the sizing rule's formulas (`δ_budget`, the panel-fit constraint) are unchanged; what changes is that the rule's own headline consequence must never be quoted again without the part size it was computed against.
