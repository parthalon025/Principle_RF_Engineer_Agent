# Knowledge ingestion

Do not start by embedding everything.

Use two stages:

1. authoritative metadata + structured extraction
2. semantic retrieval

Recommended metadata:

- source
- title
- author
- revision
- publication date
- license
- authority rank
- document type
- engineering domain
- component/manufacturer
- applicable frequency range
- temperature range
- revision/checksum

Prefer semantic sections over fixed-size chunks. Keep equations, tables,
captions, and their surrounding definitions together. Never strip units
or reference conditions.

A public URL does not automatically grant redistribution rights.
Only ingest material the organization is authorized to use.
